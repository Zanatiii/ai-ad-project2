# S mark

The original halftone "S", with its curves and proportions kept, rebuilt as clean vector. Every file here is generated by `src/`.

- Same curves as the original: the hook is the original's outer and inner curve, and its lines fan out evenly toward the tail exactly as they do in the original.
- Dots fitted per line, so a dot lands exactly on both ends and on every chevron corner.
- Hook tails taper, and the dots grow and get denser into the centre (hook ends and chevrons).
- Solid crescents and long solid blades. The blades are solid for most of their length and turn to dots only near the centre.
- The teal half is the copper half rotated 180°.

| File | Use |
|---|---|
| `s-mark.svg` / `.png` | Primary. Gradient, transparent background |
| `s-mark-on-dark` / `s-mark-on-light` | On `#0E0F12` / on `#F4F1EC` |
| `s-mark-flat`, `-white`, `-black` | Flat colours and one-colour versions |
| `s-mark-bold*` | Fewer, larger dots. Use for icons and anything under ~200px |
| `showcase.png` | Presentation frame |

Colours: copper `#C9603A` / `#E5825B` / `#F4AA84`, teal `#1E9FAC` / `#43C4CB` / `#78E2DE`.

Regenerate: `pip install numpy scipy shapely cairosvg && cd src && python3 export.py ..`. Parameters live in the `P` dict in `src/mark3.py`.
