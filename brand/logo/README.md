# S mark

Procedural vector rebuild of the halftone "S" logo. Every file here is generated by `src/`.

| File | Use |
|---|---|
| `s-mark.svg` / `.png` | Primary. Gradient, transparent background |
| `s-mark-on-dark` | Primary on brand black `#0E0F12` |
| `s-mark-on-light` | Deeper copper/teal for light backgrounds (`#F4F1EC`) |
| `s-mark-flat` | Flat colors, no gradient (print, embroidery, screen-print) |
| `s-mark-white` / `s-mark-black` | One-color versions |
| `s-mark-bold*` | Fewer, larger dots. Use this for avatars and app icons, and anywhere the mark is under ~200px |
| `showcase.png` | Presentation frame |

## Colors

| | Deep | Mid | Light |
|---|---|---|---|
| Copper | `#C9603A` | `#E8845C` | `#F6B08A` |
| Teal | `#1E9FAC` | `#43C4CB` | `#79E6E1` |

Flat: copper `#E5825B`, teal `#43C4CB`. Background: `#0E0F12`.

## Regenerate

```sh
pip install numpy scipy cairosvg
cd src && python3 export.py ..
```

Geometry and melt parameters live in the `P` dict at the top of `src/logo.py`.
