# S mark

A halftone "S" built on a construction grid. Every file here is generated by `src/`. See `construction.png`.

## Construction

- **Angles.** Only three directions are used for straight elements: the slash at 51.83° (arccos 1/φ), the line at 90° to the slash, and horizontal. Every chevron is a right angle to the slash.
- **One centre per half.** The hook lines and the spine lines are concentric circles around C, so the line spacing and the hook-to-spine gap are constant everywhere.
- **Tangent runs.** Every straight run leaves its circle tangentially, so there are no kinks.
- **Ends on offsets.** Hook ends and tails sit on lines at S/2 from the slash. The two apex dots are exactly one pitch apart.
- **Exact dot fitting.** Each line's pitch is fitted so a dot lands exactly on both ends and on every chevron corner. Dots stop one clearance (P−D) away from any solid shape.
- **Symmetry.** The teal half is the copper half rotated 180°.

| Module | Value |
|---|---|
| S, line spacing | 15 |
| P, dot pitch | 11.5 |
| D, dot | 8.4 |
| hook / spine gap | 1.5 S |
| lines | 8 hook, 5 spine |

## Files

| File | Use |
|---|---|
| `s-mark.svg` / `.png` | Primary. Gradient, transparent background |
| `s-mark-on-dark` | Primary on `#0E0F12` |
| `s-mark-on-light` | Deeper colours for light backgrounds (`#F4F1EC`) |
| `s-mark-flat` | Flat colours (print, embroidery) |
| `s-mark-white` / `s-mark-black` | One colour |
| `s-mark-bold*` | Same system with 5 + 3 lines and larger dots. Use for avatars, app icons, and anything under ~200px |
| `showcase.png` | Presentation frame |
| `construction.png` | Construction sheet |

## Regenerate

```sh
pip install numpy shapely cairosvg
cd src && python3 export.py ..
```

All parameters live in the `P` dict at the top of `src/mark.py`.
